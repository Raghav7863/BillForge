# BillForge

BillForge is a full-stack invoice and billing SaaS built to simplify invoice management for small businesses.

### Features
- Secure authentication with Google and email/password
- Dashboard for invoice and billing overview
- Client and product management
- Create, edit, and delete invoices
- Invoice status tracking
- PDF invoice generation and download
- Email invoices with PDF attachments
- Responsive, modern UI

### Tech Stack
- Next.js
- React
- TypeScript
- MongoDB & Mongoose
- Auth.js (NextAuth)
- Tailwind CSS
- Framer Motion
- Nodemailer
- Puppeteer
